GITHUB PAGES YAYIN PAKETI v0.53

1. GitHub hesabinizda afsarad.github.io adinda bir public repository olusturun (varsa mevcut Pages repository kullanin).
2. Bu ZIP dosyasini telefonunuza indirin ve ZIP icindeki dosyalari cikarin.
3. Repository > Add file > Upload files secin.
4. ZIP dosyasini tek parca olarak DEGIL, icindeki dosyalari repository kokune yukleyin.
5. Commit changes ile kaydedin.
6. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
7. Yayininiz https://afsarad.github.io/ adresinde acilabilir. Repo adi farkliysa adres de farkli olur.
8. index.html Turkce, index-english.html Ingilizce ana sayfadir.
9. Siteyi yayinlamadan once metinleri, gorselleri ve baglantilari tarayicida inceleyin.

Not: Onceki HTML sayfalarinin bazilari paket kaynaklarinda bulunmadigindan ilgili baglantilar var olan site bolumlerine yonlendirildi. Bu sayfalarin tam metinleri uretilmedi. Kitap kapaklarinin gercek eser kapaklariyla uyumu yayindan once kontrol edilmelidir.
